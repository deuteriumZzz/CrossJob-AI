**CrossJob-AI** — персональный помощник в поиске работы с понятным дашбордом. Рутину он
берёт на себя: находит вакансии, оценивает, насколько вы подходите, пишет сопроводительные
под каждую вакансию и ведёт переписку. Решения остаются за вами: сообщения HR и письма
компаниям уходят только после вашего нажатия.

## Три способа выйти на работодателя

Можно пользоваться одним или всеми сразу.

| | Как работает | Что делаете вы |
|---|---|---|
| **1. Площадки** | Бот по расписанию ищет вакансии на 9 площадках, ИИ оценивает соответствие резюме (1–10), пишет сопроводительное и откликается сам или только показывает находки | Включаете площадки и выбираете режим: «Откликается сам» или «Только ищет» |
| **2. Telegram-парсер** | Постоянно слушает каналы с вакансиями. Пост с вашими словами за секунды приходит в CrossJob-бот с кнопками «Здравствуйте», «+ резюме», «Сопроводительное» | Нажимаете кнопку — сообщение уходит HR с вашего личного аккаунта |
| **3. Своя база компаний и рассылка** | База пополняется сама — из Telegram-парсера и канала «🏢 Сайты компаний» — и вашими списками (Excel, CSV, PDF, открытые наборы вроде [careerLauncher](https://github.com/byborh/careerLauncher)). Рассылка пишет каждой компании персональное письмо и отправляет через ваш Gmail с резюме во вложении — по одному, в рабочее время, как человек | Загружаете список, просматриваете письма и нажимаете «Начать отправку» |

Путь третьего способа: **компании попадают в Базу → «Рассылка» пишет письма → бот отправляет их порциями → ответы приходят во «Входящие»**.

## Возможности

**Поиск и отклики**
- 🔍 Поиск по вашим должностям и городам на 9 площадках, чёрные списки компаний, слов и локаций, фильтр удалёнки «только США/Европа».
- 🎯 Оценка соответствия: ИИ ставит балл 1–10 и объясняет, чего не хватает; слабые совпадения не тратят отклик.
- 🚀 Автоотклик или режим «Только ищет», дневные лимиты, паузы между откликами; одна вакансия с нескольких площадок получает один отклик.
- 🧪 «Проверить площадки, ничего не отправляя» — пробный прогон, чтобы увидеть, что бот нашёл бы.
- 🔝 Поднятие резюме на hh и профиля на Djinni по расписанию.

**Telegram-парсер**
- ⚡ Постоянное подключение к каналам: вакансия приходит за секунды, а не раз в N часов.
- 📨 Кнопки в CrossJob-боте: «Здравствуйте», «+ резюме» (свои PDF под разные роли), «Сопроводительное под вакансию».
- 📇 Контакты HR из постов сами попадают в базу компаний; новые каналы подхватываются на ходу, в закрытые для аккаунта парсер вступает сам.

**Компании и рассылка**
- 🗂 База компаний: таблица с сортировкой, статусами (не писали / черновик / написали / ответили / возврат / не писать), источником каждого контакта и историей. База только пополняется — сама ничего не удаляет.
- 🔄 Статус меняется сам, откуда бы ни ушло письмо: из рассылки, из Telegram-парсера или из «Входящих». Кому уже написали — рассылка второй раз не напишет; ответ и возврат ловятся из Gmail.
- 🏢 «Сайты компаний» собирают в Базу компании с подходящими вакансиями (Greenhouse, Lever, Ashby, Workable, We Work Remotely, HN «Who is hiring») и ищут email HR: в тексте вакансии, на сайте компании, через Hunter.
- 📥 Импорт своего списка: Excel, CSV, Markdown, PDF, Word, TXT. Таблицы читаются по заголовкам столбцов, таблица в PDF — по расположению ячеек, без ИИ; свободный текст раскладывает ИИ, но email берётся, только если он дословно есть в файле. Домены проверяются по MX, ящики для жалоб и доступности (accessibility@, fraud@…) отбрасываются, всё видно в предпросмотре до сохранения. Где взять список — [промт для ИИ](#как-собрать-базу-компаний-с-помощью-ии).
- 📚 Тысячи компаний: страницы по 50/100/200, «Выбрать все по фильтру», фильтры по статусу, источнику, конкретному файлу и наличию email, поиск.
- ✉️ Рассылка: персональное письмо каждой компании (кто я → почему вы → 2–3 достижения → звонок, 150–180 слов), обращение по имени HR. Компаниям из России и СНГ (домен .ru/.by/.kz… или вакансия по-русски) — по-русски, остальным — по-английски. Письма пишутся порциями по дневному лимиту, следующая порция готовится сама. Новые компании Базы встают в очередь идущей рассылки и получают письмо первыми — они актуальнее. Каждая новая порция ждёт вашего «🚀 Отправить все» — или включите «Бот отправляет новые порции сам» (первую порцию рассылки вы смотрите всегда).
- 🛡 Отправка без блокировки Gmail: разогрев ящика, рабочие часы, случайные паузы, стоп при возвратах — [подробнее](#рассылка-без-блокировки-gmail). Напоминание в той же ветке тем, кто молчит 7+ дней.
- 🧹 Дубли компаний объединяются по домену сайта или почты (несколько HR одной компании — одна карточка и одно письмо), выгрузка в Excel, ежедневная резервная копия.

**Общение и ответы**
- 📬 «Входящие»: приглашения, вопросы HR и ответы на письма простыми словами; по умолчанию «Главное», отказы — отдельным фильтром.
- ✍️ Черновики ответов HR в Telegram и чате hh на подтверждение, автоответ в чате hh (по желанию).
- 🎤 Подготовка к интервью: справка по вакансии, тренажёр с разбором ответов, событие в календарь.

**Аналитика**
- 📊 Результат за 7 дней по каждому источнику: отправлено, ответили, интервью, % отклика.
- Воронка до оффера, спрос на навыки против вашего резюме, зарплаты на рынке, чего чаще всего не хватает, кандидаты в чёрный список.

## Быстрый старт

**Готовое приложение** (macOS/Windows) — [скачайте релиз](#скачать) и откройте. При первом запуске мастер на Главной проведёт по шагам: резюме → ключ ИИ → площадки → CrossJob-бот → Telegram → Gmail → «▶ Запустить».

**Из исходников:**

```bash
git clone https://github.com/deuteriumZzz/CrossJob-AI.git
cd CrossJob-AI
pip install -r requirements.txt -r requirements-desktop.txt
python desktop_app.py
```

Дашборд в обычном браузере (слушает только `127.0.0.1`):

```bash
uvicorn src.webui.api:app
```

Без интерфейса — консольное меню или запуск по расписанию:

```bash
python main.py                    # меню
python main.py --auto headhunter  # или geekjob / getmatch / telegram / linkedin / habr_career / wellfound / himalayas / djinni / all
python main.py --daemon           # встроенный планировщик вместо cron
```

Первый запуск без `data_folder/` создаёт его из шаблона `data_folder_example/`. Пошагово — в [полном гайде](docs/GUIDE.md).

## Интерфейс

Шесть разделов, у каждого одна задача:

| Раздел | Что там |
|---|---|
| **Главная** | Мастер настройки по шагам — пока не настроено главное (резюме, ключ ИИ, площадка); потом одна тихая строка «можно ещё подключить…» (скрывается ✕), а если что-то сломалось — строкой в «Что сделать сейчас»; «Что сделать сейчас» (черновики, новые ответы, интервью, площадки на паузе), «Свои каналы» — «🏢 Компании и рассылка» (весь путь в одной карточке: одна кнопка следующего шага — загрузить список, написать письма, просмотреть и отправить, остановить; просмотр писем и загрузка файла — в боковой панели, без перехода) и «✈️ Telegram-парсер», карточки площадок с переключателем и режимом |
| **Вакансии** | Всё, что нашёл бот: статус, этап, балл, письмо; у вакансии «Действия» — найти HR, подготовка к интервью, тренажёр, календарь, заполнить форму. Отказы по умолчанию скрыты |
| **Общение** | Входящие (ответы работодателей и «Ждут вашего решения») · Telegram-парсер (как работает, подключение аккаунта, диалоги) |
| **Компании** | База (таблица компаний и HR на тысячи строк, импорт файла с промтом «Где взять список компаний?», выгрузка в Excel) · Рассылки (база → письма → отправка через Gmail, статистика, напоминания) |
| **Аналитика** | Результат за 7 дней, воронка, навыки, зарплаты, офферы, кандидаты в чёрный список |
| **Настройки** | Подключения (все аккаунты и площадки со статусом, Hunter) · Что ищу · Площадки · Лимиты · ✈️ Telegram-парсер · 🏢 Сайты компаний · Почта и письма (Gmail, 🛡 защита почты, Hunter) · 🤖 CrossJob-бот · Провайдер ИИ · Ещё (автозапуск, расходы на ИИ) · Мои резюме · Логи |

- Одна кнопка «▶ Запустить / Остановить» в меню — поиск и отклики на площадках. Рассылка от неё не зависит: раз нажали «Начать отправку», письма уходят, пока открыто приложение.
- Строка «Сейчас» в меню видна с любой страницы: 🔄 отправляю (7 из 25 сегодня, следующее через ~9 мин), ⏸ рассылка ждёт (вечер, выходные, лимит), ⛔ остановлено — с кнопкой «что делать». Там же разбор файла и проверка площадки.
- Изменения видно сразу: «База обновлена: +N компаний», новые строки на пару секунд подсвечиваются, цифры на карточках плавно досчитываются.
- Настройки сохраняются сами; ключи и пароли — отдельной кнопкой.
- Кнопка «?» — короткая справка «Как пользоваться».
- Светлая и тёмная тема, работает и на узком экране.

## CrossJob-бот в Telegram

Ваш личный бот уведомлений (создаётся за минуту через @BotFather). Пишет только вам — HR его не видят.

- Вакансии из Telegram-парсера с кнопками ответа.
- Письма рассылки и напоминания: «🚀 Отправить все» или «👀 Показать по одному» с кнопками «Отправить / Пропустить / 🚫 Не писать» у каждого письма.
- «🚫 Не писать компании» под вакансией и письмом — компания получает в Базе статус «не писать» и выпадает из рассылок.
- Ответы работодателей, приглашения, черновики на подтверждение, предупреждения (капча, вход, лимиты).
- ⛔ Остановка рассылки, где нужны вы (Gmail не принял пароль, волна возвратов), — сразу и один раз; обычные паузы — в сводке.
- Утренняя сводка; 🔕 тихий режим — несрочное только в сводке, ответы HR и интервью приходят сразу.
- Команды: `/status`, `/pause hh`, `/resume hh` (после капчи).

## Как собрать базу компаний с помощью ИИ

Список компаний с адресами HR можно попросить у ИИ, но **только в режиме с поиском в интернете**: ChatGPT → Deep Research или Claude → Research. Обычный чат без поиска придумывает адреса вида `hr@company.com` — такие письма возвращаются, а волна возвратов портит репутацию вашей почты в Gmail.

1. Откройте ИИ с поиском и вставьте промт ниже, поменяв то, что в [скобках]. Этот же промт есть в дашборде: **Компании → База → «Где взять список компаний?»** с кнопкой «Скопировать».
2. Попросите сохранить таблицу файлом Excel или CSV (или скопируйте её в Google Таблицы → «Файл → Скачать → CSV»). Таблица в PDF тоже подойдёт.
3. Загрузите файл: **Компании → База → «📥 Загрузить файл»**.

```text
Найди [30] IT-компаний, которые сейчас нанимают [Python-разработчиков] [в России / удалённо в Европе], и публичные адреса для откликов в них.

Правила:
1. Используй поиск в интернете. Бери email только с официальных страниц: сайт компании (разделы «Карьера», «Вакансии», «Контакты»), страница вакансии, официальный профиль компании.
2. Не угадывай и не составляй адреса по шаблону (например, hr@компания.ru). Нет опубликованного адреса — оставь ячейку пустой.
3. Не бери адреса для жалоб, доступности и особых запросов (accessibility@, accommodations@, fraud@, eeo@).
4. Для каждой строки укажи ссылку на страницу, где опубликован email.

Ответ — одна таблица без текста вокруг, столбцы по порядку:
Компания | Сайт | Email | Имя | Должность | Вакансия | Ссылка | Источник
«Должность» — должность человека из столбца «Имя»; «Ссылка» — ссылка на вакансию, если есть; «Источник» — страница, где опубликован email.
```

**Что происходит при загрузке.** Бот читает столбцы по заголовкам (русским или английским), проверяет, что у домена есть почтовый сервер, отбрасывает ящики для жалоб и доступности, склеивает дубли с тем, что уже есть в Базе, и показывает предпросмотр — сохраняется только после вашего «Добавить». Имя и должность HR идут в обращение письма, вакансия — в текст, источник — в карточку контакта.

**Что загружается, а что нет.** Импорт пополняет **Базу компаний для рассылки**. Вакансии из файла сохраняются в карточке компании, и письмо пишется под них, но во «Вакансии» и автоотклик на площадках они не попадают.

**Готовые открытые списки.** Например, [careerLauncher](https://github.com/byborh/careerLauncher) — публичные адреса для откликов в tech-компаниях со ссылкой на источник (файл `data/companies.md`, лицензия ODC-BY — указывайте источник). Скачайте его и загрузите как обычный файл.

## Рассылка без блокировки Gmail

Рассылка идёт через ваш личный Gmail, поэтому она устроена так, чтобы выглядеть как письма живого человека, а не спам. Всё настраивается в **Настройки → Почта и письма → 🛡 Защита почты**.

| Защита | Как работает | По умолчанию |
|---|---|---|
| **Дневной лимит** | Не больше N писем в день (до 300) | 30 |
| **Разогрев ящика** | Первый день — 15 писем, дальше +5 за каждый день, когда письма уходили, пока не дойдёт до вашего лимита. Резкий скачок с нуля до сотен писем — главный признак спама | включён |
| **Время отправки** | Только в заданные часы; вечером и в выходные бот ждёт и продолжает сам | будни, 9:00–19:00 |
| **Паузы как у человека** | Оставшиеся письма дня распределяются по оставшемуся рабочему времени, ±50% случайно, иногда перерыв на 10–25 минут | — |
| **Стоп при возвратах** | N возвратов за сутки (адреса не существуют) — отправка встаёт до завтра, в бот приходит сообщение. N настраивается (1–30); разумно держать долю возвратов ниже 3–5% писем за день | 3 |
| **Пароль Gmail не принят** | Рассылка сразу встаёт, а не тратит впустую остальные письма; новый пароль в настройках снимает стоп | — |

**Сколько писем в день безопасно.** Обычный Gmail технически позволяет около 500 писем в день, но для писем незнакомым людям разумно 30–50. До 80–100 — только на ящике, который уже несколько недель отправляет письма и получает ответы. Разогрев доводит до вашего лимита постепенно — не выключайте его на новом ящике.

Письма ИИ пишет порциями по дневному лимиту: список на тысячу компаний не превращается в тысячу запросов к ИИ разом, а письма не устаревают, пока ждут очереди. Сколько дней займёт вся рассылка с учётом разогрева — видно в «Рассылках».

## Письма как от человека

Всё, что уходит работодателю, пишется по правилам скилла [humanizer](https://github.com/blader/humanizer) (основан на Wikipedia «Signs of AI writing»), дополненным русскими словами-маркерами: без «не просто X, а Y», тире-связок, троек по шаблону, раздутой значимости, рекламного тона и остатков чат-бота; только факты из резюме.

Затем вторая проверка, как в самом скилле: код ищет оставшиеся признаки, и если они есть, ИИ один раз переписывает текст с сохранением всех фактов. Это касается писем рассылки, сообщений HR в Telegram, сопроводительных, ответов в чате hh и текстовых ответов в анкетах hh.

Имя в теме и подписи берётся из того же PDF-резюме, что уходит во вложении.

## Что делает ИИ и по каким правилам

ИИ в CrossJob работает только там, где без него никак: оценить вакансию, написать текст, понять ответ HR. У каждой задачи свой промт — полный текст в коде по ссылке, здесь — смысл.

| Что делает ИИ | Что получает | Главные правила | Промт |
|---|---|---|---|
| Оценка вакансии, балл 1–10 | резюме, вакансия, её зарплата и ваши ожидания | 2–4 пункта «чего не хватает»; балл жёстко ниже, если грейд выше вашего уровня, нет обязательных навыков или зарплата ниже ожиданий | [job_fit.py](src/job_sources/job_fit.py) |
| Сопроводительное к отклику | резюме, вакансия | их главная задача → 2–3 примера из резюме с цифрами → честно назвать один пробел → почему именно эта компания; до 250 слов, на языке вакансии, без заготовок вроде «[Company Name]» | [plain_cover_letter_prompt*](src/libs/resume_and_cover_builder/) |
| Первое сообщение HR (кнопки Telegram-парсера) | резюме, текст вакансии | 2–3 главных требования и на каждое пример из резюме; без клише; на языке поста | [hr_replies.py](src/job_sources/hr_replies.py) |
| Письмо компании (рассылка) | резюме, компания, сайт, вакансия, имя HR, «упор» из файла | обращение по имени, 3 абзаца, 150–180 слов, звонок в конце; компаниям России и СНГ — по-русски, остальным — по-английски | [hr_replies.py](src/job_sources/hr_replies.py) |
| Разбор ответа HR | текст сообщения | приглашение / вопрос / отказ / другое — так ответы раскладываются во «Входящих» | [hr_replies.py](src/job_sources/hr_replies.py) |
| Ответ в чате hh | резюме, сообщение работодателя | сначала решает, нужен ли ответ (статусы и автоматика hh — нет); факта нет — говорит прямо, особенно про зарплату и опыт | [reply_answerer.py](src/job_sources/reply_answerer.py) |
| Анкета работодателя на hh | резюме, вакансия, вопросы | варианты выбирает только из предложенных, дословно; текст — кратко, от первого лица; отправка — после вашего «да» | [form_fill.py](src/job_sources/headhunter/form_fill.py) |
| Анкета LinkedIn Easy Apply | резюме, профиль, вопрос | коротко, только факты, всегда по-английски | [answerer.py](src/job_sources/linkedin/answerer.py) |
| Разбор поста Telegram | текст поста | компания, должность, зарплата — только то, что написано; контакты находит код, а не ИИ | [post_parser.py](src/job_sources/telegram/post_parser.py) |
| Разбор списка компаний из текста или PDF | текст файла, частями | только то, что написано; email принимается, лишь если он дословно есть в файле | [importer.py](src/direct/importer.py) |
| Подготовка к интервью и тренажёр | резюме, вакансия, чего не хватает | вопросы с тезисами ответа из резюме; о компании известно только название — «проверьте на сайте компании»; оценка ответа 1–10 | [interview_prep.py](src/job_sources/interview_prep.py) |
| Интервью в календарь | сообщение HR | только точные дата и время; «на следующей неделе» — событие не создаётся | [interview_calendar.py](src/job_sources/interview_calendar.py) |
| Аудит резюме | резюме, вакансия | честный разбор рекрутера, проверка ATS, опыт по формуле Google XYZ; чисел нет — метка [ЗАПОЛНИТЬ], а не выдуманные цифры | [resume_audit.py](src/job_sources/resume_audit.py) |
| Должности для поиска | резюме | 2–4 названия, как их ищут на job-сайтах | [resume_profile.py](src/job_sources/resume_profile.py) |
| Проверка «как от человека» | готовый текст | остались признаки ИИ — одна переделка с сохранением всех фактов; вышло в 1,6 раза длиннее — остаётся исходный текст | [anti_ai_rules.py](src/libs/resume_and_cover_builder/anti_ai_rules.py) |

**Чего ИИ никогда не делает**
- **Не придумывает факты о вас.** Опыт, стаж, цифры и навыки берутся только из резюме. Нет нужной цифры — ставится [ЗАПОЛНИТЬ] или честное «нет данных».
- **Не придумывает адреса.** Email и Telegram-контакты находит код в тексте; из файла адрес берётся, только если он там дословно.
- **Не придумывает факты о компании** — только то, что есть в вакансии и данных.
- **Ничего не отправляет сам.** Письма, сообщения HR и анкеты уходят после вашего нажатия. Сам бот отправляет только отклики в режиме «Откликается сам» и уже просмотренные вами письма рассылки.
- **Ваши данные видит только выбранный вами провайдер ИИ** (Настройки → Провайдер ИИ) по вашему ключу: резюме и текст вакансии уходят ему ровно для этой задачи.

## Данные и безопасность

- **Всё хранится у вас на компьютере** в `data_folder/`: база компаний (`output/contact_book.json`), рассылки, отклики, переписка, черновики. В git не попадает.
- **База только пополняется** — компании, контакты и история сами не удаляются, только вручную (с «Отменить»).
- **Запасная копия** всей Базы и остальных файлов делается сама раз в день в `data_folder/backups/`; хранятся копии за последние 7 дней — на случай, если файл испортится или что-то удалили по ошибке.
- **Ничего не уходит HR без вашего нажатия** — сообщения в Telegram, письма рассылки и напоминания только по кнопке. Сам бот отправляет лишь отклики на площадках в режиме «Откликается сам».
- **Пароли бот не вводит:** вход на площадки и в Telegram делаете вы; для Gmail — пароль приложения Google, а не основной пароль.
- Сопроводительные к откликам хранятся 7 дней; письма из Telegram-кнопок — в `data_folder/telegram/letters/`.

## Лимиты и анти-бан

Лимиты — наши собственные настройки пацинга, а не официальные цифры площадок. Меняются в **Настройки → Лимиты** без перезапуска; каждый прогон пишет в лог воронку по площадке (найдено / уже видели / отсеялось / откликнулись).

| Площадка | Дневной лимит | За прогон | Защита |
|---|---|---|---|
| HeadHunter | 15 (±70–100% случайно) | 5 | Пауза на 24 ч при капче или бане |
| LinkedIn | 8 (±70–100%) | 5 | Официального API нет — см. оговорку в [GUIDE.md](docs/GUIDE.md) |
| Хабр Карьера, Wellfound, Himalayas, Djinni | общий дневной лимит или свой у площадки | 5 | Пауза на 24 ч при капче или бане |
| geekjob, GetMatch | своего нет — лимит за прогон | 5 | Пауза на 24 ч при капче или бане |
| Telegram | 15 холодных сообщений в день (если включены автосообщения) | — | Личный аккаунт |
| Рассылка по почте | `email_daily_limit` (по умолчанию 30) с разогревом от 15 в день | по одному, случайные паузы по рабочему дню | Рабочие часы, стоп при возвратах (по умолчанию 3 за сутки) — см. [Рассылка без блокировки Gmail](#рассылка-без-блокировки-gmail) |

Плюс `apply_once_at_company` (не откликаться в одну компанию дважды) и общий потолок `limits.total_daily_application_limit`.

## Конфигурация

Почти всё настраивается в дашборде. Если удобнее файлами:

- **`data_folder/secrets.yaml`** — ключи ИИ (`llm_api_keys`, 14 провайдеров; по умолчанию рекомендуем бесплатный Groq с моделью `openai/gpt-oss-120b`), `telegram: {api_id, api_hash}` с [my.telegram.org](https://my.telegram.org/apps), бот уведомлений `notifications`, почта `email: {address, app_password}`, необязательный `hunter_api_key`.
- **`data_folder/work_preferences.yaml`** — должности, локации, чёрные списки, фильтры; блок на каждую площадку (`schedule_enabled`, `interval_hours`, `auto_apply`, свои `positions`/`locations`, лимиты); `telegram:` (`channels`, `watch_enabled`, `watch_keywords`, `watch_stop_words`, приветствие); `djinni:` (`country`, `experience_years`, `auto_bump_resume`); `headhunter.auto_bump_resume`, `headhunter.auto_reply`; `direct:` («Сайты компаний» и почта: `schedule_enabled`, `companies`, `wwr`, `hn`, `email_daily_limit`, `warmup`, `send_from`, `send_to`, `weekdays_only`, `follow_up_days`); `digest: {enabled, hour, quiet}`; `excluded_remote_regions`.
- **Резюме** — `data_folder/resume.pdf` (основное), `resume_linkedin.pdf` (зарубежные площадки и английские письма), дополнительные PDF в `data_folder/telegram/` (кнопки в Telegram и выбор в рассылке). Удобнее загружать в **Настройки → Мои резюме**.
- **Логи** — `log/app.log` (ротация 10 МБ, неделя), видны в **Настройки → Логи**.

Полное описание каждого поля — в [GUIDE.md](docs/GUIDE.md).
