**CrossJob-AI** — персональный помощник в поиске работы с понятным дашбордом. Рутину он
берёт на себя: находит вакансии, оценивает, насколько вы подходите, пишет сопроводительные
под каждую вакансию и ведёт переписку. Решения остаются за вами: сообщения HR и письма
компаниям уходят только после вашего нажатия.

## Три способа выйти на работодателя

Можно пользоваться одним или всеми сразу.

| | Как работает | Что делаете вы |
|---|---|---|
| **1. Площадки** | Бот по расписанию ищет вакансии на 9 площадках, ИИ оценивает соответствие резюме (1–10), пишет сопроводительное и откликается сам или только показывает находки | Включаете площадки и выбираете режим: «Откликается сам» или «Только ищет» |
| **2. Telegram-парсер** | Постоянно слушает каналы с вакансиями. Пост с вашими словами за секунды приходит в CrossJob-бот с кнопками «Здравствуйте», «+ резюме», «Сопроводительное» | Нажимаете кнопку — сообщение уходит HR с вашего личного аккаунта |
| **3. Рассылка по базе компаний** | Собирает базу компаний и HR (ваш файл, Telegram, вакансии), пишет каждой компании персональное письмо и отправляет через ваш Gmail с резюме во вложении | Просматриваете письма и нажимаете «Отправить» |

## Возможности

**Поиск и отклики**
- 🔍 Поиск по вашим должностям и городам на 9 площадках, чёрные списки компаний, слов и локаций, фильтр удалёнки «только США/Европа».
- 🎯 Оценка соответствия: ИИ ставит балл 1–10 и объясняет, чего не хватает; слабые совпадения не тратят отклик.
- 🚀 Автоотклик или режим «Только ищет», дневные лимиты, паузы между откликами; одна вакансия с нескольких площадок получает один отклик.
- 🧪 «Проверить площадки, ничего не отправляя» — пробный прогон, чтобы увидеть, что бот нашёл бы.
- 🔝 Поднятие резюме на hh и профиля на Djinni по расписанию.

**Telegram-парсер**
- ⚡ Постоянное подключение к каналам: вакансия приходит за секунды, а не раз в N часов.
- 📨 Кнопки в CrossJob-боте: «Здравствуйте», «+ резюме» (свои PDF под разные роли), «Сопроводительное под вакансию».
- 📇 Контакты HR из постов сами попадают в базу компаний; новые каналы подхватываются на ходу, в закрытые для аккаунта парсер вступает сам.

**Компании и рассылка**
- 🗂 База компаний: таблица с сортировкой, статусами (не писали / черновик / написали / ответили / возврат / не писать), источником каждого контакта и историей.
- 📥 Импорт своего списка: Excel, CSV, TXT, PDF, Word (например, ответ Claude Research). Большой PDF разбирается в фоне по частям; email берётся, только если он дословно есть в файле; домены проверяются по MX.
- ✉️ Рассылка: персональное письмо каждой компании (кто я → почему вы → 2–3 достижения → звонок, 150–180 слов, тема «[Должность] Application — Имя Фамилия»), отправка через Gmail по одному с паузой, статистика, возвраты, напоминание в той же ветке тем, кто молчит 7+ дней.
- 🧹 Дубли компаний объединяются по домену сайта или почты, выгрузка в Excel, ежедневная резервная копия.

**Общение и ответы**
- 📬 «Входящие»: приглашения, вопросы HR и ответы на письма простыми словами; по умолчанию «Главное», отказы — отдельным фильтром.
- ✍️ Черновики ответов HR в Telegram и чате hh на подтверждение, автоответ в чате hh (по желанию).
- 🎤 Подготовка к интервью: справка по вакансии, тренажёр с разбором ответов, событие в календарь.

**Аналитика**
- 📊 Результат за 7 дней по каждому источнику: отправлено, ответили, интервью, % отклика.
- Воронка до оффера, спрос на навыки против вашего резюме, зарплаты на рынке, чего чаще всего не хватает, кандидаты в чёрный список.

## Быстрый старт

**Готовое приложение** (macOS/Windows) — [скачайте релиз](#скачать) и откройте. При первом запуске мастер на Главной проведёт по шагам: резюме → ключ ИИ → площадки → CrossJob-бот → Telegram → Gmail → «▶ Запустить».

**Из исходников:**

```bash
git clone https://github.com/deuteriumZzz/CrossJob-AI.git
cd CrossJob-AI
pip install -r requirements.txt -r requirements-desktop.txt
python desktop_app.py
```

Дашборд в обычном браузере (слушает только `127.0.0.1`):

```bash
uvicorn src.webui.api:app
```

Без интерфейса — консольное меню или запуск по расписанию:

```bash
python main.py                    # меню
python main.py --auto headhunter  # или geekjob / getmatch / telegram / linkedin / habr_career / wellfound / himalayas / djinni / all
python main.py --daemon           # встроенный планировщик вместо cron
```

Первый запуск без `data_folder/` создаёт его из шаблона `data_folder_example/`. Пошагово — в [полном гайде](docs/GUIDE.md).

| Раздел | Что там |
|---|---|
| **Главная** | Мастер настройки по шагам (пока что-то не подключено), «Что сделать сейчас» (черновики, новые ответы, интервью, площадки на паузе), «Свои каналы» — карточки Telegram-парсера и отправки почты, карточки площадок с переключателем и режимом |

| **Общение** | Входящие (ответы работодателей и «Ждут вашего решения») · Telegram-парсер (как работает, подключение аккаунта, диалоги) |
| **Компании** | База (таблица компаний и HR, импорт файла, выгрузка в Excel) · Рассылки (база → письма → отправка через Gmail, статистика, напоминания) |

| **Настройки** | Подключения (все аккаунты и площадки со статусом) · Что ищу · Площадки · Лимиты · ✈️ Telegram-парсер · Почта и письма · 🤖 CrossJob-бот · Провайдер ИИ · Ещё (автозапуск, расходы на ИИ) · Мои резюме · Логи |

- Одна кнопка «▶ Запустить / Остановить» в меню; рядом видно, что бот делает прямо сейчас (рассылка, разбор файла, проверка площадки).
- Настройки сохраняются сами; ключи и пароли — отдельной кнопкой.
- Кнопка «?» — короткая справка «Как пользоваться».
- Светлая и тёмная тема, работает и на узком экране.

## CrossJob-бот в Telegram

Ваш личный бот уведомлений (создаётся за минуту через @BotFather). Пишет только вам — HR его не видят.

- Вакансии из Telegram-парсера с кнопками ответа.
- Письма рассылки и напоминания: «🚀 Отправить все» или «👀 Показать по одному» с кнопками «Отправить / Пропустить» у каждого письма.
- Ответы работодателей, приглашения, черновики на подтверждение, предупреждения (капча, вход, лимиты).
- Утренняя сводка; 🔕 тихий режим — несрочное только в сводке, ответы HR и интервью приходят сразу.
- Команды: `/status`, `/pause hh`, `/resume hh` (после капчи).

## Письма как от человека

Всё, что уходит работодателю, пишется по правилам скилла [humanizer](https://github.com/blader/humanizer) (основан на Wikipedia «Signs of AI writing»), дополненным русскими словами-маркерами: без «не просто X, а Y», тире-связок, троек по шаблону, раздутой значимости, рекламного тона и остатков чат-бота; только факты из резюме.

Затем вторая проверка, как в самом скилле: код ищет оставшиеся признаки, и если они есть, ИИ один раз переписывает текст с сохранением всех фактов. Это касается писем рассылки, сообщений HR в Telegram, сопроводительных, ответов в чате hh и текстовых ответов в анкетах hh.

Имя в теме и подписи берётся из того же PDF-резюме, что уходит во вложении.

## Данные и безопасность

- **Всё хранится у вас на компьютере** в `data_folder/`: база компаний (`output/contact_book.json`), рассылки, отклики, переписка, черновики. В git не попадает.
- **Резервная копия** этих файлов делается сама раз в день в `data_folder/backups/`, хранятся 7 последних.
- **Ничего не уходит HR без вашего нажатия** — сообщения в Telegram, письма рассылки и напоминания только по кнопке. Сам бот отправляет лишь отклики на площадках в режиме «Откликается сам».
- **Пароли бот не вводит:** вход на площадки и в Telegram делаете вы; для Gmail — пароль приложения Google, а не основной пароль.
- Сопроводительные к откликам хранятся 7 дней; письма из Telegram-кнопок — в `data_folder/telegram/letters/`.

## Лимиты и анти-бан

Лимиты — наши собственные настройки пацинга, а не официальные цифры площадок. Меняются в **Настройки → Лимиты** без перезапуска; каждый прогон пишет в лог воронку по площадке (найдено / уже видели / отсеялось / откликнулись).

| Площадка | Дневной лимит | За прогон | Защита |
|---|---|---|---|
| HeadHunter | 15 (±70–100% случайно) | 5 | Пауза на 24 ч при капче или бане |
| LinkedIn | 8 (±70–100%) | 5 | Официального API нет — см. оговорку в [GUIDE.md](docs/GUIDE.md) |
| Хабр Карьера, Wellfound, Himalayas, Djinni | общий дневной лимит или свой у площадки | 5 | Пауза на 24 ч при капче или бане |
| geekjob, GetMatch | своего нет — лимит за прогон | 5 | Пауза на 24 ч при капче или бане |
| Telegram | 15 холодных сообщений в день (если включены автосообщения) | — | Личный аккаунт |
| Рассылка по почте | `email_daily_limit` (по умолчанию 20) | по одному, пауза 1–2 мин | Gmail, одна ветка на компанию |

Плюс `apply_once_at_company` (не откликаться в одну компанию дважды) и общий потолок `limits.total_daily_application_limit`.

## Конфигурация

Почти всё настраивается в дашборде. Если удобнее файлами:

- **`data_folder/secrets.yaml`** — ключи ИИ (`llm_api_keys`, 14 провайдеров; по умолчанию рекомендуем бесплатный Groq с моделью `openai/gpt-oss-120b`), `telegram: {api_id, api_hash}` с [my.telegram.org](https://my.telegram.org/apps), бот уведомлений `notifications`, почта `email: {address, app_password}`, необязательный `hunter_api_key`.
- **`data_folder/work_preferences.yaml`** — должности, локации, чёрные списки, фильтры; блок на каждую площадку (`schedule_enabled`, `interval_hours`, `auto_apply`, свои `positions`/`locations`, лимиты); `telegram:` (`channels`, `watch_enabled`, `watch_keywords`, `watch_stop_words`, приветствие); `djinni:` (`country`, `experience_years`, `auto_bump_resume`); `headhunter.auto_bump_resume`, `headhunter.auto_reply`; `direct:` (прямой поиск и почта: `email_daily_limit`, `follow_up_days`); `digest: {enabled, hour, quiet}`; `excluded_remote_regions`.
- **Резюме** — `data_folder/resume.pdf` (основное), `resume_linkedin.pdf` (зарубежные площадки и английские письма), дополнительные PDF в `data_folder/telegram/` (кнопки в Telegram и выбор в рассылке). Удобнее загружать в **Настройки → Мои резюме**.
- **Логи** — `log/app.log` (ротация 10 МБ, неделя), видны в **Настройки → Логи**.

Полное описание каждого поля — в [GUIDE.md](docs/GUIDE.md).

## Разработка

```bash
pip install -r requirements.txt -r requirements-desktop.txt
black --line-length 79 --check .
isort --profile black --line-length 79 --check .
flake8 --max-line-length=79 --select=E,F --extend-ignore=E704
mypy --ignore-missing-imports main.py src desktop_app.py
python -m pytest tests/ -q
```

Те же проверки гоняются в CI на каждый push и PR в `main` ([ci.yml](.github/workflows/ci.yml)).

| Где | Что |
|---|---|
| `main.py`, `desktop_app.py` | Точки входа: консольное меню, планировщик, десктоп-окно |

| `src/webui/` | FastAPI-дашборд (`api.py`) и интерфейс (`static/`) |
| `src/libs/resume_and_cover_builder/` | Генерация резюме и сопроводительных, правила humanizer (`anti_ai_rules.py`) |
| `tests/` | Юнит-тесты |
