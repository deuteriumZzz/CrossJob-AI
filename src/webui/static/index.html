Подключение

Читает каналы и пишет контактам через твой личный аккаунт (не бота) — вход по api_id/api_hash с my.telegram.org в data_folder/secrets.yaml (блок telegram:). При первом запуске поиска по Telegram в консоли попросит номер телефона и код из самого Telegram — дальше сессия сохраняется, повторно вводить не нужно.

Каналы и правила поиска

⚠️ Даже с паузами и лимитом это холодные сообщения незнакомым людям с твоего личного аккаунта — Telegram может ограничить аккаунт при слишком активной рассылке. Первое сообщение — только короткое приветствие с интересом к вакансии, без резюме и без автоответа на входящие: продолжать разговор (в т.ч. присылать резюме, если попросят) — вручную, из диалогов ниже.

    Настройки

    Расписание, автоотклик и уведомления

    Поиск

    Должности (ключевые слова поиска, они же — ключевые слова для Telegram-каналов) и локации — без правки work_preferences.yaml вручную. Настройки самого Telegram (каналы, автосообщения, диалоги) — на вкладке «Telegram» слева.

    Провайдер LLM

    Переключение применяется сразу, без перезапуска — для всех вызовов LLM (оценка вакансий, письма, резюме).

    Если выключить переключение — используется строго выбранный выше провайдер, без ухода на другие ключи из настроек ниже, даже если они настроены. Режим (авто/бесплатно/платно) определяет, какие из настроенных ключей участвуют в цепочке переключения и в каком порядке.

    Лимиты откликов

    ⚠️ Официальных цифр лимитов не публикует ни одна площадка — заданные здесь значения только уменьшают риск, но не гарантируют, что бота не заметят. Чем выше лимиты и чем ближе они к количеству найденных вакансий, тем больше активность похожа на бота. Повышайте постепенно, начните с малого. LinkedIn блокирует автоматизацию агрессивнее остальных — держите его лимит ниже.

    Ориентир для старта: HH и остальные — 15/день, LinkedIn — 8/день, не больше 5 откликов за один прогон, интервал между прогонами — от 3ч. Поднимайте эти числа только если несколько дней подряд не видите капчи/блокировок.

    Общий лимит — это жёсткий потолок: как только сегодня суммарно по ВСЕМ площадкам отправлено столько откликов, автооткликер останавливается везде, даже если у отдельной площадки в таблице ниже свой лимит ещё не исчерпан. Дневной лимит и максимум за один заход выше — то, что действует для площадки, у которой нет своего значения в таблице ниже (галочка "своё значение" в соответствующей колонке выключена). Включите галочку у нужной площадки, чтобы задать число только для неё — не трогая остальные.

    Уведомления (Telegram-бот)

    Отдельный бот только для уведомлений вам — не путать с вкладкой "Telegram" слева (там про поиск по каналам и переписку с контактами). Присылает статус площадок, исчерпание лимитов, расходы на LLM, подтверждение нестандартных анкет HH — и отвечает на команды /status, /pause <площадка>, /resume <площадка> прямо из чата.

    Ещё нет бота?
    1. В Telegram напишите @BotFather, отправьте /newbot, задайте имя — в ответ придёт токен.
    2. Вставьте токен в поле выше и нажмите "Подключить" — откроется чат с ботом, нажмите там Start, дальше всё подхватится само (chat_id и приветственное сообщение).

    Автозапуск

    Запускать приложение (и демон внутри него) автоматически при входе в систему — не нужно вручную открывать CrossJob-AI после перезагрузки. macOS — LaunchAgent, Windows — автозапуск через реестр.
