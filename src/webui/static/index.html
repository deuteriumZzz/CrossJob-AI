Подключение

Читает каналы и пишет контактам через твой личный аккаунт (не бота) — вход по api_id/api_hash с my.telegram.org в data_folder/secrets.yaml (блок telegram:). При первом запуске поиска по Telegram в консоли попросит номер телефона и код из самого Telegram — дальше сессия сохраняется, повторно вводить не нужно.

Каналы и правила поиска

⚠️ Даже с паузами и лимитом это холодные сообщения незнакомым людям с твоего личного аккаунта — Telegram может ограничить аккаунт при слишком активной рассылке.     Поиск

    Должности (ключевые слова поиска, они же — ключевые слова для Telegram-каналов) и локации — без правки work_preferences.yaml вручную. Настройки самого Telegram (каналы, автосообщения, диалоги) — на вкладке «Telegram» слева.

    Провайдер LLM

    Переключение применяется сразу, без перезапуска — для всех вызовов LLM (оценка вакансий, письма, резюме).

    Если выключить переключение — используется строго выбранный выше провайдер, без ухода на другие ключи из настроек ниже, даже если они настроены. Режим (авто/бесплатно/платно) определяет, какие из настроенных ключей участвуют в цепочке переключения и в каком порядке.

    Лимиты откликов

    ⚠️ Официальных цифр лимитов не публикует ни одна площадка — заданные здесь значения только уменьшают риск, но не гарантируют, что бота не заметят. Чем выше лимиты и чем ближе они к количеству найденных вакансий, тем больше активность похожа на бота. Повышайте постепенно, начните с малого. LinkedIn блокирует автоматизацию агрессивнее остальных — держите его лимит ниже.

    Ориентир для старта (это дефолты самого бота, не гарантия от бана): HH / SuperJob / Zarplata — 15/день, LinkedIn — 8/день, не больше 5 откликов за один прогон, интервал между прогонами — от 3ч. Поднимайте эти числа только если несколько дней подряд не видите капчи/блокировок.

    Общий лимит — это жёсткий потолок: как только сегодня суммарно по ВСЕМ площадкам отправлено столько откликов, автооткликер останавливается везде, даже если у отдельной площадки в таблице ниже свой лимит ещё не исчерпан. Лимиты по площадкам — то, как этот общий бюджет распределяется между ними (например 10 на HH + 2 на GetMatch + 8 на LinkedIn = 20).

    Уведомления (Telegram-бот)

    Отдельный бот только для уведомлений вам — не путать с вкладкой "Telegram" слева (там про поиск по каналам и переписку с контактами). Нужен для уведомлений (новые ответы работодателей, дневной лимит откликов исчерпан, расходы на LLM) на всех площадках, а для HeadHunter — ещё и для подтверждения автозаполнения внешних анкет (Google Forms по ссылке из чата с работодателем): бот присылает черновик ответов и ждёт вашего "да <id>" / "заново <id>" / "правка <id> <номер> <текст>" в ответ, прежде чем что-то отправить.

    Как получить токен и chat_id (один раз)
    1. В Telegram напишите @BotFather, отправьте /newbot, задайте имя — в ответ придёт telegram_bot_token.
    2. Напишите своему новому боту любое сообщение (например "привет") — иначе бот не сможет писать вам первым.
    3. Откройте в браузере https://api.telegram.org/bot<TOKEN>/getUpdates и найдите "chat":{"id": ...} — это telegram_chat_id.
    4. Впишите оба значения в data_folder/secrets.yaml: 
      notifications:
  telegram_bot_token: "..."
  telegram_chat_id: "..."
      (правится только руками в файле — то же самое, что и ключ LLM-провайдера выше).
