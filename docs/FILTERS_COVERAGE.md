Не нужны общим фильтром (специфика одной-двух площадок): английский, релокация, без агентств, тип компании.

## Подключено 2026-10-08: офис и гибрид на GetMatch и Avito, период на GetMatch
- **GetMatch:** `l=` по чекбоксам «Офис или гибрид в …» (`moscow`, `saints_p`, `regions_ru`, `relocate`) и «Удалённо» (`remote`); офис и гибрид у сайта один пункт, поэтому идут вместе. Период — `pa=1d / 3d / 7d / 30d`. Значения проверены по адресу после клика и по отмеченным чекбоксам. Замечание: сайт запоминает выбранные фильтры в сессии, поэтому при выборе формата параметры `l=` передаются явно.
- **Avito:** офис — радио «В офисе или на объекте» + кнопка «Найти» (вживую по «python»: 84 из 89, дважды). Гибрид применяется (в адресе `f=`), в выдаче «python» гибридных объявлений нет. Сайт принимает клик не каждый раз, поэтому результат сверяется и клик повторяется один раз. Обычный клик Selenium по радио не проходит, нужен клик из страницы. «Удалённо» — как раньше, через адрес. Работает при выборе ровно одного формата: у Avito радио, а не флажки.
